## VU3INI PacketLab v1.0.0

Design, simulate and test **LAN, MAN and WAN** networks to current industry standards — fully offline on Windows 10/11.

### Install
1. Download **VU3INI_PacketLab_Installer_v1.0.0.zip** below and extract the whole zip.
2. Run **VU3INI_PacketLab_Setup_v1.0.0.exe** (no admin rights or Internet needed).
3. If SmartScreen appears: **More info → Run anyway** (the app is not code-signed).

The installer includes the optional NVIDIA GPU add-on (CuPy + CUDA 12). Without an NVIDIA card, PacketLab runs on the CPU.

### Highlights
- Packet Tracer-style canvas with LAN / MAN / WAN site zones
- VLANs, RSTP, LACP, G.8032, OSPF, IS-IS, BGP, MPLS, VRRP, DHCP, DNS, NAT, ACLs, IPsec
- Realtime and Simulation modes, PDU inspector and Wireshark .pcapng export
- IOS-style CLI on every device
- Automated tests including failover timing, RFC 2544, Y.1564 and TWAMP
- Export to Containerlab / Kathará (FRRouting)
